# Blue Detected — الحزمة الكاملة

تضم هذه الحزمة مصدر تطبيق Windows، وموقع Blue Detected وخدمة API، مع إعدادات PostgreSQL مناسبة للنشر على Render.

## المجلدات
- `PCCheck-Lite/`: مصدر تطبيق Windows Forms وملفات الموارد وسكربت بناء EXE.
- `server/`: الموقع وخدمة API وقاعدة بيانات PostgreSQL وإعدادات البيئة.
- `render.yaml`: إعداد خدمة الموقع على Render.

## وظائف التطبيق وAPI
- فحص آثار النظام ذات الصلة مثل BAM وUSB وآثار الملفات وسجلات Defender، وفق ما يدعمه الكود.
- واجهة API محلية للتقدم، ثم إرسال التقرير إلى الخدمة البعيدة عبر `/validate-code` و`/submit`.
- عنوان الخادم الافتراضي داخل `PCCheck-Lite/server.txt` هو `https://blue-detected.onrender.com`. غيّره إلى عنوان Render الفعلي قبل بناء التطبيق إذا كان مختلفًا.
- لا يُفترض إرسال المستندات الشخصية أو كلمات المرور. راجع التقرير والبيانات التي يجمعها الفحص قبل توزيع التطبيق.

## بناء تطبيق Windows
1. افتح الحزمة على جهاز Windows.
2. راجع `PCCheck-Lite/server.txt` وتأكد من أنه عنوان HTTPS الصحيح.
3. شغّل `PCCheck-Lite/build.bat` من Windows. يعتمد سكربت البناء على مترجم C# الخاص بـ .NET Framework الموجود في المسار الافتراضي.
4. سيُنشأ الملف التنفيذي داخل `PCCheck-Lite/Blue Detected/`.

هذه الحزمة تحتوي على **المصدر وسكربت البناء**؛ لم يتم تضمين EXE مبني ومختبَر على Windows في هذه البيئة.

## إعداد Render
1. ارفع محتويات هذه الحزمة إلى مستودع GitHub.
2. أنشئ PostgreSQL على Render، ثم انسخ رابط الاتصال الداخلي إلى `DATABASE_URL` في خدمة الويب.
3. أنشئ Web Service من المستودع مع Root Directory = `server`، Build Command = `npm ci`، Start Command = `npm start`.
4. اضبط المتغيرات المطلوبة في `server/.env.example` داخل Render: `DATABASE_URL`, `BASE_URL`, `ADMIN_TOKEN`, `SESSION_SECRET`, `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET`. استخدم أسرارًا عشوائية قوية ولا تضعها في GitHub.
5. اجعل `BASE_URL` عنوان HTTPS العام الصحيح، واضبط Redirect URI في تطبيق Discord إلى `/auth/discord/callback`.
6. تحقق من `/health` ثم أنشئ رمزًا تجريبيًا وارسل تقريرًا تجريبيًا قبل الاستخدام الحقيقي.

## تصنيف التقرير
تُعرض المؤشرات حسب مستويات الخطورة: Critical / High / Medium / Low. أما Clean / Suspicious / Formatting Required / Cheating فهي قرارات مراجعة بشرية وليست استنتاجات آلية مؤكدة. اسم ملف أو سجل مفقود وحده لا يثبت الغش.

## الخصوصية والأمان
- لا تنشر ملف `.env` أو رموز الإدارة أو أسرار قاعدة البيانات.
- لا تعطّل Microsoft Defender لتشغيل التطبيق. افحص أي تنبيه أمني قبل توزيع EXE.
- احتفظ فقط بالبيانات الضرورية، وحدد مدة الاحتفاظ بالتقارير في إعدادات الخدمة.
- اختبر النظام على قاعدة بيانات تجريبية قبل استيراد بيانات حقيقية.

## ملاحظة مهمة
الموقع وخدمة API يستخدمان تدفق مفاتيح/تقارير الخدمة الرئيسية. يوجد أيضًا `owner-server.js` لتدفق لوحة المالك المنفصل؛ توضح README داخل `server/` أنه يستخدم مسارًا وقاعدة بيانات/رموزًا منفصلة، ولا تتم مزامنته تلقائيًا مع تدفق الموقع الرئيسي.
