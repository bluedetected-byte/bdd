BLUE DETECTED — REDESIGN 2026

Cette archive contient la version redesign du site Blue Detected, inspirée de la référence fournie :
- Page d'accueil sombre bleu nuit, accents bleus et aperçu de scan circulaire.
- Section fonctionnalités, étapes, FAQ et aperçu du tableau de bord.
- Tableau de bord staff avec barre latérale responsive, statistiques, filtres, codes de vérification et panneau de détail des rapports.
- Les routes et le backend Express existants sont conservés.

Installation rapide :
1. Extraire tous les fichiers dans le dossier du site.
2. Installer Node.js LTS.
3. Dans ce dossier, exécuter : npm install
4. Configurer les variables d'environnement déjà attendues par server.js (Discord, base URL, stockage et accès admin).
5. Exécuter : npm start

Important : l'aperçu graphique de la page d'accueil utilise des éléments CSS/SVG illustratifs. Les rapports réels restent ceux envoyés par l'application et disponibles via les routes backend. Testez la connexion Discord et la réception des rapports dans votre environnement avant mise en production.
